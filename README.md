# Customer Churn Analysis using Python

## Project Overview
This project analyzes customer churn data to identify patterns associated with customer cancellations. Python was used for data processing, analysis, and visualization.

## Tools and Technologies
- Python
- Pandas
- NumPy
- Matplotlib
- CSV dataset

## Project Objectives
- Analyze customer churn rate.
- Compare churn across different contract types.
- Analyze churn by internet service.
- Study customer tenure and monthly charges.
- Identify customer groups that may need retention support.

## Key Findings
- Total customers analyzed: 7,043
- Customers who left: 1,869
- Customers who stayed: 5,174
- Overall churn rate: 26.54%
- Month-to-month contract churn rate: 42.71%
- Fiber optic customer churn rate: 41.89%
- Customers with less than one year of tenure had a churn rate of 48.28%.
- Customers who left had a lower average tenure than customers who stayed.

## Recommendations
- Investigate ways to improve the experience of new customers.
- Review the needs and concerns of month-to-month contract customers.
- Investigate customer feedback and service issues among fiber optic users.
- Monitor churn rates regularly to evaluate retention efforts.

## Visualizations
The project generates charts showing:
1. Customers who stayed versus customers who left.
2. Customer churn by contract type.
3. Average monthly charges by churn status.

## Project Outputs
- Cleaned customer churn dataset
- Churn visualization charts
- Contract-wise churn analysis
- Internet-service-wise churn analysis
- Tenure-group churn analysis

## Conclusion
This analysis identifies customer segments with higher churn rates and provides insights that can support data-driven customer retention strategies.
